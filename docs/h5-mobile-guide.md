# 趣邻圈 H5 页面帮助文档（移动端）

> 适用对象：通过手机浏览器或微信访问 H5 页面的用户
> 文档版本：v1.0（2026-09-06）
> 访问方式：在手机浏览器地址栏输入运营方提供的 H5 地址（形如 `https://<H5域名>/`），或点击他人分享的页面链接

---

## 一、页面功能说明

趣邻圈是一款基于「兴趣标签 + 地理位置」的同好社交应用，H5 版与小程序版功能一致。主要页面如下：

### 1. 登录与账号

| 页面 | 功能说明 |
| --- | --- |
| 登录页 | 支持手机号 + 短信验证码登录、微信快捷登录（仅微信内有效） |
| 个人资料（profile） | 修改昵称、头像、邮箱、微信号、地址定位、兴趣标签、练习年限、活跃度 |
| 隐私设置（privacy） | 控制是否允许匹配、位置精度（精确 / 社区 / 区域）；「公开联系方式」开关不影响联系方式的解锁 |
| 关于我们（about） | 产品介绍与协议入口 |

### 2. 发现与匹配

| 页面 | 功能说明 |
| --- | --- |
| 首页（index） | 兴趣标签选择、基于位置的同趣圈与人推荐入口 |
| 匹配结果（match） | 按「同趣的圈」「同趣的人」两个维度展示匹配结果，支持下拉刷新 |

### 3. 人-人联系（打招呼）

| 页面 | 功能说明 |
| --- | --- |
| 用户主页（user-home） | 查看对方资料、关注 / 取关、发起打招呼；双方互相接受打招呼后解锁展示联系方式（微信号 / 手机号），支持一键复制，手机号可直接拨打 |
| 联系请求（contact-requests） | 「我收到的 / 我发出的」双列表：接受、拒绝、撤回打招呼请求 |
| 我关注的人（followed-users） | 查看并管理已关注的用户列表 |

> 联系方式解锁规则：只能在双方**已互相接受打招呼**后才可见，对方**主动公开**联系方式与解锁限制无关；微信号优先展示，对方未填微信号时会展示其手机号（需满足同样权限）。任何人任何时候都无法看到对方的登录邮箱。

### 4. 圈子与活动

| 页面 | 功能说明 |
| --- | --- |
| 圈子详情（circle） | 圈子信息、成员、活动；可查看老师联系电话 / 微信并拨打或复制 |
| 创建圈子（create-circle） | 发布新圈子（需填写联系电话或微信号至少一项） |
| 我的圈子 / 我关注的圈子 / 我发布的圈子 | 圈子管理入口 |
| 活动 / 活动列表 / 创建活动 / 活动管理 | 活动发布、报名与管理 |

### 5. 消息与认证

| 页面 | 功能说明 |
| --- | --- |
| 消息（notifications） | 系统通知：新的联系请求、联系已建立、新增关注、圈子审核类通知，点击可跳转对应页面 |
| 教师认证（teacher-certification） | TEACHER 角色认证申请入口 |

## 二、操作步骤（常见任务）

### 任务 1：登录

1. 打开 H5 地址，进入首页；
2. 点击任意需登录的功能（或「我的」），系统自动跳转登录页；
3. 输入手机号 → 获取验证码 → 输入验证码 → 登录；
4. 登录成功后自动返回之前浏览的页面。

### 任务 2：找到同趣的人并打招呼

1. 首页完善兴趣标签与位置信息；
2. 进入「匹配结果」页，切换到「同趣的人」；
3. 点击感兴趣的人，进入其用户主页；
4. 点击「打个招呼」，可附一句自我介绍（≤100 字），发送后等待对方处理；
5. 对方接受后，底部操作条展示「微信号：xxx」或「手机号：xxx」，点击「复制」或「拨打」即可联系。

### 任务 3：处理收到的打招呼

1. 进入「我的」→「联系请求」（或从「消息」通知点入）；
2. 在「我收到的」列表中点击「接受」或「拒绝」；
3. 接受后双方均可互看联系方式。

### 任务 4：修改自己的微信号

1. 进入「我的」→「个人资料」；
2. 点击微信号一栏的编辑图标，弹出「修改微信号」弹窗；
3. 输入新微信号（≤50 字符），留空则清除；点击「保存」即时生效。

### 任务 5：调整谁能看到我的联系方式

1. 进入「我的」→「隐私设置」；
2. 「公开联系方式」开关**不控制**联系方式的可见性——只有你**接受了对方的打招呼**，对方才能看到你的联系方式；
3. 位置精度建议选「社区」或「区域」，避免暴露精确住址。

## 三、移动端适配要求

为获得完整、可截图的显示效果，请满足以下条件：

| 项目 | 要求 |
| --- | --- |
| 浏览器 | iOS 12+ Safari、Android 8+ Chrome / 厂商浏览器、微信内置浏览器（WeChat 8+） |
| 屏幕与方向 | 竖屏使用；已适配 320px–428px 宽度（iPhone SE ~ Pro Max），小屏页面可纵向滚动 |
| 安全区 | 底部操作条已适配 iPhone 刘海屏 / 全面屏安全区（safe-area-inset），无需手动设置 |
| 网络 | HTTPS 正常访问即可；页面弱网下会显示「加载中…」，可下拉刷新重试 |
| 字体缩放 | 系统超大字体下部分文字可能截断（显示省略号），不影响功能；截图建议用标准字号 |
| 登录态 | 大部分页面需登录；未登录访问会引导登录而非报错，「关于我们」等公开页无需登录 |

## 四、截图方式说明

### 方式 1：系统截图（推荐，所有页面可用）

H5 页面在浏览器中与其他网页无异，直接使用手机系统截图：

| 平台 | 操作 |
| --- | --- |
| iPhone（Face ID 机型） | 同时按「侧边电源键 + 音量上键」 |
| iPhone（Home 键机型） | 同时按「电源键 + Home 键」 |
| Android（通用） | 同时按「电源键 + 音量下键」 |
| Android（部分品牌） | 下拉通知栏点击「截图」；或三指下滑 / 指关节双击（依品牌手势而定） |
| 长截图 | iOS：截图后点左下角缩略图选「整页」；Android：多数机型在截图预览中提供「滚动截图 / 长截图」按钮 |

**截图前准备：**
1. 等待页面完全加载（骨架 / 「加载中…」消失）；
2. 滚动到要展示的内容位置再截图；
3. 弹窗（如微信号复制提示）会在 1–2 秒后自动消失，需要拍提示内容的请在弹窗出现的瞬间截图。

### 方式 2：页面内截图按钮

**当前版本未提供页面内截图按钮。** 原因：在微信内置浏览器及多数移动浏览器中，网页脚本无法调用系统截图能力，只能通过 Canvas 重绘页面（如 html2canvas）生成图片，该方案对复杂样式（渐变、emoji 图标、远程图片跨域）还原度有限，故暂未上线。若后续版本提供「保存为图片」按钮，会出现在页面右上角菜单中，届时截图文件将保存至手机相册。

### 微信内使用的特别说明

- 在微信中打开 H5 时，可点击右上角「…」→「截屏反馈」或「在浏览器打开」；
- 微信内长按页面中的**图片**可直接保存单张图片，但**整页内容**仍需系统截图；
- 部分安卓机在微信内截屏会触发安全提示，属正常现象，不影响截图保存。

## 五、常见问题与注意事项

### Q1：打开页面一直显示「加载中…」？
多为网络波动或后端服务暂时不可用。请下拉刷新重试；若持续失败，检查手机网络或稍后再试。

### Q2：提示需要登录 / 页面自动跳到登录页？
大部分页面需要登录后访问（如用户主页、消息、联系请求）。完成登录后会自动返回原页面，无需重新寻找入口。

### Q3：对方主页为什么看不到联系方式？
联系方式只有在双方**已互相接受打招呼**后才会展示（对方是否公开联系方式不影响此规则）。看不到通常是以下原因之一：① 你尚未与其建立联系——先「打个招呼」，对方接受后即可看到；② 你发出的请求还在等待对方处理；③ 你最近一次请求被拒绝，可重新发起。对方接受后即可看到其微信号（未填微信号时展示手机号）。

### Q4：微信号 / 手机号复制了但没提示？
复制成功会有 Toast 提示「已复制」。若无提示，可长按输入框选择「粘贴」验证；个别浏览器出于安全策略会静默失败，可改为手动记录。

### Q5：点击「拨打」没有反应？
拨打按钮仅对手机号类型的联系方式生效，且需浏览器允许唤起拨号盘。微信内置浏览器部分版本会拦截，可点击「…」→「在浏览器打开」后重试。

### Q6：截图后分享是否安全？——**请务必阅读**
- 截图可能包含**他人的微信号、手机号、头像与昵称**，这些信息受隐私规则保护。请勿将含他人联系方式的截图公开发布到社交平台或群聊；
- 分享前建议先裁剪掉敏感信息，或仅在对方知情的情况下分享；
- 你自己的联系方式截图同样存在被冒用的风险，谨慎分享。

### Q7：页面样式错乱 / 白屏？
- 尝试刷新页面或清理浏览器缓存；
- 确认浏览器为较新版本（旧内核不支持页面使用的现代 CSS 特性）；
- 微信内异常时可换系统浏览器打开对比。

### 注意事项汇总

1. 每人每日最多发起 **10 次**打招呼（撤回不返还额度），超限次日自动恢复；
2. 同一对用户同时只能存在一条待处理打招呼请求；
3. 兴趣标签、位置信息越完整，匹配结果越精准；
4. 隐私设置中的「位置精度」影响他人看到你的距离，建议非必要时不用「精确」；
5. 遇到骚扰可通过拒绝打招呼 + 不公开联系方式自我保护；异常行为可向运营方反馈（附上相关页面截图更高效）。
